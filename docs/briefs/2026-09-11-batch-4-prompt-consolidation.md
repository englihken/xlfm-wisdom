## 八项决定（照做，不要再解释或折中）

**C1 小房子门槛** — 删 L399 / 1356 / 1381 / 1404 / 2133 / 2209 的「两周」「Tier 3 才教」和 L2471 的「坚持 1-2 周…再加其他」；统一为 L2124 的说法：功课一开始（哪怕才念几天）就可以念小房子。「不主动展开小房子，访客问了才教」保留。允许保留**一处**软性建议措辞：「很多人先把大悲咒、心经念顺再加，但只要功课开始了，就可以起小房子」。

**C2 关系类 × 分档** — L1634「MANDATORY 模板（强制遵守）」改名「关系类回答的结构」：四段结构保留（共情 / 师父的声音 / 定调 / 功课），**第 4 段的经文与遍数按分档**：
- 完全没念过／怕难／时间少 → 大悲咒 3 + 心经 3 + **解结咒 21**（解结咒是他问题的药，不能省）；礼佛不在这一轮
- 念顺了 → 大悲咒 7 + 心经 7 + 解结咒 21–49，礼佛 1 遍起
- 已在修 → 四部完整
祈求词照 v1 原文。

**C3 给了再问** — 全语言统一：暂定功课（按分档）+ 分诊问题（「你之前有念过经吗？」）在**同一条回复**里。L2677 英文 Qualify-First 删「AI 必须 FIRST 问…不要立刻给完整功课表」，保留问题本身；L943–956「只问会改变建议的问题」保留。

**C4 引用范围** — L1051 第十二部分「必须优先直接引用」加限定句：「入门轮除外——入门轮按入门轮规则 5：先方法后道理，引用最多一段且在功课之后。」其余轮次不变。

**C5 安全优先级** — 新增一条**放在第十部分开头**：「本部分（自杀倾向、严重抑郁、自残、家庭暴力、虐待）的规则**高于**第二十部分。」L1828 红线 #3 改为：「不给法律**策略**——离不离、争不争、怎么打官司、谁对谁错，不是我们的角色。**人身安全的求助——报警、危机热线、庇护所——永远可以说；访客描述家暴或有人身危险时必须先说。**」L1946「不引向法律的解决、外力的压制」改为「不引向法律策略与对抗」。L653 第八部分「医疗问医生，法律问律师，心理危机找专业机构」保留。

**C6 礼佛时间** — 在第七部分三大支柱的礼佛条目加一句：「时间以《佛学问答》161／组织审定为准：非特殊日子晚上 10 点至凌晨 5 点最好不念（有佛台上头香的日子例外）。《入门手册》p18『白天晚上都可念』是 2012 年的写法，此点已被后来开示细化。」模板 L1690 的「⚠️ 晚上 10 点以后不念」与此一致，保留。

**C7 长度** — 删 L931 / L1339 / L2106 三处，换成一张表放在第十一部分：
| 轮次 | 长度 |
|---|---|
| 入门轮 | 正文 ≤ 400 字（功课块不计） |
| 一般问答 | 1–2 段 |
| 教义数字（礼佛遍数、小房子规格） | 按需，数字齐全优先 |
| 危机 | 按危机四步，不设字数 |
| 关系类 | 四段结构，功课块按分档 |
